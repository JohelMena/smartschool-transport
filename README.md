# 🚌 SmartSchool Transport

## 📘 Descripción
**SmartSchool Transport** es una aplicación  diseñada para automatizar el proceso de matrícula y el control del transporte estudiantil.  
El sistema permite registrar estudiantes, encargados, choferes, buses y rutas, así como controlar la asistencia diaria de los estudiantes en el transporte.  
Incluye autenticación por roles (Administrador, Secretaría y Chofer) y generación de reportes, garantizando eficiencia, control y seguridad en los procesos escolares.
